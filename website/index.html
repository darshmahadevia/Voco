A few things
before you speak.

What do I need to run Voco?

An Apple Silicon Mac running macOS 26 or newer. Voco currently supports English dictation. Setup includes a speech-model download and microphone and keyboard access.

Does my voice leave my Mac?

Speech recognition runs locally. After the initial model download, dictation works offline. Voco does not save audio. Optional recent transcripts stay in memory until you quit.

Where can I use it?

In text fields across your Mac. Click where you want your words, hold Fn or Globe, speak, then release. Voco does not write into password fields or submit forms for you. Some apps may restrict text insertion. If insertion fails, your transcript remains available to copy.

Is Voco really free?

Yes. Voco is free to download and use. No account, subscription, or paid API key is required.

What should I know about early access?

This build is not notarized by Apple. macOS may block it from opening. Read the release notes and installation instructions before installing. Only proceed if you trust the download. Accuracy and processing time depend on your model, speech, and Mac.
