Voco turns speech into text on your Mac. Put your cursor in a text field, hold your dictation shortcut, speak, and release. Once transcription finishes, Voco inserts the completed words into that field.

Dictation is processed locally. Your audio is not uploaded to a remote transcription service. You need an internet connection to download a speech model during setup, then you can dictate offline.

The current build requires an Apple Silicon Mac running macOS 26 or later. Intel Macs and Windows are not supported by this release. Dictation currently supports English.

Yes. Voco is free to download and use. There is no account, subscription, usage credit, or API key to set up. Your Mac runs the speech model.

This is an early access build and is not notarized by Apple. macOS may prevent it from opening by default. Read the release notes and review the project before choosing to install. Only bypass the warning if you trust the source.

Microphone access lets Voco hear you while you dictate. Accessibility access lets it insert the completed text into your active app. Voco walks you through both permissions during setup.
