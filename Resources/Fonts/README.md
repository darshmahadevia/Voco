# Manrope

Voco embeds Manrope Regular, Medium, and SemiBold at weights 400, 500, and 600. All instances retain the family name `Manrope` and their corresponding weight metadata.

Medium and SemiBold were instantiated with FontTools 4.62.1 from the [Google Fonts variable source](https://github.com/google/fonts/blob/main/ofl/manrope/Manrope%5Bwght%5D.ttf) on October 16, 2026. Regular was already bundled by the Rust migration.

The fonts use the [SIL Open Font License](OFL.txt). Font generation is a development operation. The application embeds the resulting TTF files and does not require Python or FontTools.
