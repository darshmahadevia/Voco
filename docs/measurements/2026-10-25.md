# File transcription measurements, October 25, 2026

The release application transcribed the same 17.369-second synthetic speech clip five times per installed engine on an Apple M4 Mac with 10 cores, 16 GiB RAM, and macOS 27.0.1. All ten processes exited successfully and returned a nonempty transcript.

| Engine | Median total wall time | Run range | Audio duration divided by wall time | Median process maximum RSS |
| --- | ---: | ---: | ---: | ---: |
| Parakeet | 1.384 s | 1.335 to 1.420 s | 12.55 | 1201.5 MiB |
| Whisper | 2.818 s | 2.766 to 9.202 s | 6.16 | 1795.1 MiB |

## What the timer includes

Each trial starts a fresh release CLI process. Wall time includes process startup, WAV decoding, pinned-model checksum verification, model loading, inference, and transcript output. The filesystem cache may be warm. These are model-load-inclusive file transcription times, not warm inference time, app startup time, microphone latency, or cursor-insertion latency. RSS is the maximum for each CLI process, not the idle app's footprint.

The runner alternates engine order every round. The first Whisper trial took 9.202 seconds, and it remains in the range and median calculation. The trial did not control filesystem or Metal caches. An excluded one-second Whisper startup profile shows SHA-256 model verification, reads, and model initialization, confirming that startup work is present in this timing. Its [thread sample](2026-10-25/whisper-profile.txt) is separate from the timed trials. Parakeet uses the configured CPU ONNX runtime. Whisper uses the configured Metal backend. Moonshine was not installed and was not measured. Model selection is unchanged. This experiment does not establish which engine is best for ordinary dictation.

## Audio and output checks

The fixture uses macOS `say`, Samantha voice, at 165 words per minute. `afconvert` creates a mono 16 kHz, 16-bit PCM WAV. The reference text, WAV, generation commands, and audio hash are retained under [fixtures](fixtures). Each trial records its transcript and case-insensitive, punctuation-insensitive word-edit distance from that reference. The raw report includes those fixture-specific error rates. Whisper matched all 50 normalized reference words in all five runs. Parakeet substituted "right" for "write" in all five runs, one word edit per trial.

Repeated recognition of one generated clip is not an independent accuracy dataset. Do not claim a general word error rate, accent robustness, real-user recognition quality, or time saved from these results. Microphone permission was unavailable, so this run did not exercise live speech capture.

## Reproduce

```sh
cargo build --release --locked
python3 scripts/benchmark-transcription.py \
  --audio docs/measurements/fixtures/speech.wav \
  --expected docs/measurements/fixtures/speech.txt \
  --output docs/measurements/my-run
```

Use a fresh output directory. The selected models must already be installed. The command reads existing model files without changing settings or transcripts.
